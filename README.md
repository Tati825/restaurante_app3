# restaurante_app3
Versión con menú del restaurante hecho anteriormente
Nombre: Erika Tatiana España Valdez
El proyecto mantiene la estructura solicita, ahora se hace uso de los decoradores @property, @setter y @dataclass. Además se utiliza un menú desde el que se puede acceder a diferentes funciones al momento de realizar las acciones, como buscar o registrar un nuevo dato.
